# Store the state variables for the BQS model

Store the state variables for the BQS model

## Usage

``` r
# S3 method for class 'BQS'
save_states_M(t, model)
```

## Arguments

- t:

  the current time

- model:

  a model defined as a compound \[list\]

## Value

a \[list\] with the most recent states
