# Make a movie of a simulation with a BQS model

Make a movie of a simulation with a BQS model

``` r
# S3 method for class 'BQS'
make_movie(model, moviestemx = "BQSmovie")
```

## Arguments

- model:

  a model, defined as a \[list\]

- moviestemx:

  the stem name

invisible(NULL)
