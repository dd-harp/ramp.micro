# Set initial values for the BQ model

Set initial values for the BQ model

## Usage

``` r
# S3 method for class 'basicL'
init_aquatic_model(model, L0_opts)
```

## Arguments

- model:

  a model defined as a compound \[list\]

- L0_opts:

  a list of options to overwrite defaults

## Value

model, a compound \[list\]
