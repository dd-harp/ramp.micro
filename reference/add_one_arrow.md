# Draw an arrow from (x_i, y_i) to (x_j, y_j)

Draw an arrow from (x_i, y_i) to (x_j, y_j)

Draw an arrow from (x_i, y_i) to (x_j, y_j)

## Usage

``` r
add_one_arrow(
  x_i,
  y_i,
  x_j,
  y_j,
  p = 1,
  r = 0,
  arw_lng = 0.1,
  wt = 1,
  lamp = 1,
  clr = "#CCCCCC"
)

add_one_arrow(
  x_i,
  y_i,
  x_j,
  y_j,
  p = 1,
  r = 0,
  arw_lng = 0.1,
  wt = 1,
  lamp = 1,
  clr = "#CCCCCC"
)
```

## Arguments

- x_i:

  source x value

- y_i:

  source y value

- x_j:

  destination x value

- y_j:

  destination y value

- p:

  fraction of length to plot

- r:

  the radius of a ring around destination points

- arw_lng:

  the arrow length

- wt:

  the line weight

- lamp:

  arrow width scaling factor

- clr:

  the arrow color
