## Usage

``` r
add_bent_arrows_xx(
  xy,
  M,
  mnwd = 0.05,
  bbend = 1,
  adj = 2,
  endd = 0.75,
  clr = "red"
)
```

## Arguments

- xy:

  the point set

- M:

  the dispersal matrix

- mnwd:

  the minimum width to plot

- bbend:

  a parameter to bend arrows

- adj:

  set the maximum cex for points

- endd:

  relative position of arrowhead

- clr:

  the color

## Value

invisible(NULL)
