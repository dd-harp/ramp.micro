# Add the convex hulls to a framed plot

Add the convex hulls to a framed plot

## Usage

``` r
plot_convex_hulls(graph, stretch = 1.1, lwd = 2)
```

## Arguments

- graph:

  a graphwork object

- stretch:

  make the hull slightly larger or slightly smaller

- lwd:

  hull line width

## Value

invisible(NULL)
