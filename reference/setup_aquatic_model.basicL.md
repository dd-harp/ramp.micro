# Setup an aquatic model

Setup an aquatic model

## Usage

``` r
# S3 method for class 'basicL'
setup_aquatic_model(model, aquatic_opts = list())
```

## Arguments

- model:

  a model defined as a compound \[list\]

- aquatic_opts:

  a \[list\] to overwrite defaults

## Value

a \[list\] defining an adult model
