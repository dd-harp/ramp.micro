# Set initial values for

Set initial values for

## Usage

``` r
init_aquatic_model_basicL(model, opts = list(), L0 = 10)
```

## Arguments

- model:

  a model defined as a compound \[list\]

- opts:

  a list of options to overwrite defaults

- L0:

  default initial value for larval density

## Value

the model, a compound \[list\]
