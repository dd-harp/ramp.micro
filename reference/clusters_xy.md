# Use a set of \`xy\` values as seeds for clusters

Use a set of \`xy\` values as seeds for clusters

## Usage

``` r
clusters_xy(xy, nc = 1, vr = 1)
```

## Arguments

- xy:

  a set of seeds

- nc:

  the number of points per cluster

- vr:

  the variance in the dispersion around the seed

## Value

a set of xy locations
