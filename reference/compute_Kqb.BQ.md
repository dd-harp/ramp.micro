# Compute net dispersal matrix to blood feed within one feeding cycle

Compute net dispersal matrix to blood feed within one feeding cycle

## Usage

``` r
# S3 method for class 'BQ'
compute_Kqb(model, Tmax = 100)
```

## Arguments

- model:

  a model defined as a compound \[list\]

- Tmax:

  the number of time steps

## Value

the model, a compound \[list\]
