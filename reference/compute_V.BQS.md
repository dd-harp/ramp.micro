# Compute the potential dispersion of parasites after one feeding cycle for the BQS model

Compute the potential dispersion of parasites after one feeding cycle
for the BQS model

## Usage

``` r
# S3 method for class 'BQS'
compute_V(model, Tmax = 100)
```

## Arguments

- model:

  a compound \[list\] defining a model

- Tmax:

  the last time step

## Value

the model, a compound \[list\]
