# Compute dispersal to lay eggs within one feeding cycle

Compute dispersal to lay eggs within one feeding cycle

## Usage

``` r
# S3 method for class 'BQS'
compute_Kqb(model, Tmax = 200)
```

## Arguments

- model:

  a model defined as a compound \[list\]

- Tmax:

  the number of time steps

## Value

the model, a compound \[list\]
