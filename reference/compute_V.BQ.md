# Compute the potential dispersion of parasites after one feeding cycle for the BQ model

Compute the potential dispersion of parasites after one feeding cycle
for the BQ model

## Usage

``` r
# S3 method for class 'BQ'
compute_V(model, Tmax = 100)
```

## Arguments

- model:

  a compound \[list\] defining a model

- Tmax:

  the last time step

## Value

the model, a compound \[list\]
