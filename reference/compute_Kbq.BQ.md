# Compute dispersal matrix to lay eggs within one feeding cycle

Compute dispersal matrix to lay eggs within one feeding cycle

## Usage

``` r
# S3 method for class 'BQ'
compute_Kbq(model, Tmax = 100)
```

## Arguments

- model:

  a model defined as a compound \[list\]

- Tmax:

  the number of time steps

## Value

the model, a compound \[list\]
