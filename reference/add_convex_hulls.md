# Add convex hulls around the points in a community

Add convex hulls around the points in a community

## Usage

``` r
add_convex_hulls(memix, xy, clrs, stretch = 0.1, lwd = 2, llty = 1)
```

## Arguments

- memix:

  the membership index

- xy:

  the xy locasions

- clrs:

  colors

- stretch:

  a stretch factor for the hulls

- lwd:

  the line width for plotting

- llty:

  the line type

## Value

invisible(NULL)
