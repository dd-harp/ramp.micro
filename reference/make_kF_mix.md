# Make an power function that combines an exponential and power function

Make an power function that combines an exponential and power function

## Usage

``` r
make_kF_mix(p = 0.001, k = 1, s1 = 1, s2 = 1, gamma = 1, delta = 1)
```

## Arguments

- p:

  the weight on the power function

- k:

  decay by distance

- s1:

  a scale parameter

- s2:

  a scale parameter

- gamma:

  a shape parameter

- delta:

  the power on distance

## Value

a function
