# Make Psi from a source point set to a destination point set

Make Psi from a source point set to a destination point set

## Usage

``` r
make_Psi_xy(S, D, kF = make_kF_exp(), w = 1)
```

## Arguments

- S:

  a set of source points

- D:

  a set of destination points

- kF:

  a kernel weighting function

- w:

  linear weights for the destinations

## Value

a \[matrix\], dispersal from S to D
