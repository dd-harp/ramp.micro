# Set initial values for the BQ model

Set initial values for the BQ model

## Usage

``` r
init_adult_model_BQS(model, opts = list(), B0 = 10, Q0 = 10, S0 = 10)
```

## Arguments

- model:

  a model defined as a compound \[list\]

- opts:

  a list of options to overwrite defaults

- B0:

  initial values for blood feeding mosquito density

- Q0:

  initial values for egg laying mosquito density

- S0:

  initial values for sugar feeding mosquito density

## Value

model, a compound \[list\]
