# Make the convex hull for the i^th community

Make the convex hull for the i^th community

## Usage

``` r
make_convex_hull_i(i, memix, xy)
```

## Arguments

- i:

  the i^th community

- memix:

  the community membership indices

- xy:

  the point set

## Value

the xy points that define a convex hull

a \[list\] with a hull
