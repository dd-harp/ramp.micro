## Usage

``` r
add_arrows_xx(
  xy,
  M,
  min_edge_frac = 0.01,
  r = 0,
  arw_lng = 0.1,
  lwd = 5,
  lamp = 1,
  arw_clr = "darkgreen",
  seg_clr = "#CCCCCC"
)

add_arrows_xx(

  min_edge_frac = 0.01,
  r = 0,
  arw_lng = 0.1,
  lwd = 5,
  lamp = 1,
  arw_clr = "darkgreen",
  seg_clr = "#CCCCCC"
)
```

## Arguments

- xy:

  the point set

- M:

  the dispersal matrix

- min_edge_frac:

  the fraction of the mass to plot

- r:

  the radius of a ring around destination points

- arw_lng:

  the arrow length

- lwd:

  scale the line width

- lamp:

  arrow width scaling factor

- arw_clr:

  the color to draw the arrow (asymetric part)

- seg_clr:

  the color to draw the segment (symmetric part)
