# Define a cutoff that includes a fraction of the total mass (e.g. 90 percent)

Define a cutoff that includes a fraction of the total mass (e.g. 90
percent)

## Usage

``` r
cutoffValue(M, fracMass = 0.9)
```

## Arguments

- M:

  a matrix

- fracMass:

  the fraction of mass to plot

## Value

a \[numeric\] value
